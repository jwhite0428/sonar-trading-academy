# Sonar Trading Academy — Pattern Quiz

A mobile-friendly Streamlit app for practicing pattern recognition, interpreting what a pattern *suggests*, and revealing the next bars. All charts are synthetic examples, not live BTC/Kalshi data or forecasts.

## Install on Streamlit Community Cloud (iPhone friendly)
1. Unzip the archive in iPhone Files.
2. In GitHub, make a new repository, e.g. `sonar-trading-academy`.
3. Upload **app.py** and **requirements.txt** to the repository root (not inside another folder). You can use GitHub's **Add file → Upload files** on desktop mode; if iPhone's browser won't upload a folder, upload these files individually.
4. On Streamlit Community Cloud, create an app from that repository and set main file path to `app.py`.
5. Open the deployment URL on your iPhone and optionally use Safari Share → Add to Home Screen.

## Features
- 8 hand-designed synthetic price-chart scenarios
- Pick pattern, most reasonable interpretation, and confidence
- Reveal follow-through on the same chart after submitting
- Explain the clues, invalidation and limitations
- Practice score and navigation, stored in Streamlit session for the active browsing session

## Disclaimer
Educational simulation only. Patterns do not predict reliably by themselves. The futures shown are illustrative, not sourced outcomes, and are not evidence of a pattern's empirical success rate. Never infer Kalshi probabilities from the app's scores.
